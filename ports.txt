# Port registry: every TCP port a service of mine opens on a host.        ~/sys_org/home_hub/ports.txt
#
# RULES
#  1. One number means one service, on every machine. Containers run on the home laptop and get
#     tunnelled to the work laptop on the same number (fwd, LocalForward), so a number can't be
#     reused on the other laptop either.
#  2. Each kind of service has its own range (the "range" lines). Inside a range, a "block" keeps a
#     project's ports together. Every web project gets a block of ten in 8010-8099, and all of its
#     HTTP services go in that block: web app, public site, API, tiles, mail inbox.
#  3. The usual defaults (the "reserve" lines) are never assigned. A quick `runserver`,
#     `jupyter lab` or `npm run dev` then never collides with anything listed here.
#  4. Bind to 127.0.0.1 unless there is a reason not to. Reach it with `fwd PORT` (SSH) or
#     `tailscale serve`. Plain `-p 8040:8000` opens the port to every network, Wi-Fi included.
#  5. Only ports that open on a host go here. Ports that stay inside a container or a Compose
#     network (dolt 3306 in `investment`, `db:5432` seen from `tools`) don't.
#
# HOW TO ADD ONE
#   ports next KIND [PROJECT]   first free port: in the project's block if it has one there,
#                               otherwise in the kind's range outside everyone's blocks
#   ports next block [KIND]     first free block of ten (default kind: web) for a new project
#   Then add a line below and run `ports check`.
#
# FORMAT (columns separated by spaces; everything after "#" on an entry line is the note)
#   range    FIRST-LAST  KIND      what it is for
#   block    FIRST-LAST  PROJECT   ports in FIRST-LAST belong to PROJECT (required for web)
#   reserve  PORT        why it's never assigned
#   PORT  KIND  PROJECT  SERVICE  BIND  STATUS   # where it's set
#     BIND    lo = 127.0.0.1 | ts = tailnet address | all = every interface | serve = tailscale serve
#     STATUS  ok | was:NNNN (the configs still use NNNN; move pending) | planned (not built yet)
